Advertisement Management System
The Advertisement Management System is a web-based platform designed to manage and display advertisements efficiently.
It allows administrators to create, update, and remove ads, while users can view them in a categorized and user-friendly interface.
Features
Admin Login: Secure login for administrators to manage content.
Ad Management: Add, edit, and delete advertisements.
User-Friendly UI: Easy navigation for both admin and users.
Tech Stack
Frontend: HTML, CSS, JavaScript
Backend: Node.js with Express
Database: MongoDB
Tools: Visual Studio Code, Git, GitHub
